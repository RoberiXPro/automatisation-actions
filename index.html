Comment utiliser notre putain d'outil

En résumé : tu choisis le type d'action (simple / double / triple), les boutons et les heures, puis tu colles le code généré dans la console de Chrome sur la page de suivi du temps.

1. Étapes générales

1️⃣ Ouvre la page de Time Tracking (là où il y a le bouton Fin de production, les boutons Play).

2️⃣ En restant sur la page Time tracking, appuyer le bouton F12 du clavier pour Ouvrir la fenetre de la console Chrome : F12 → onglet Console.

3️⃣ Dans ton outil, configure :

  • le type d'action (simple / double / triple),
  • les boutons (Fin prod, Pause, Play),
  • les heures (format 24h HH:MM:SS).

4️⃣ Clique sur “Générer le script JS”, copie le code généré.

5️⃣ Colle-le dans la console, appuie sur Entrée.

2. “Allow pasting” dans Chrome

La première fois que tu colles du gros code dans la console Chrome, elle peut être relou et protéger :

Si Chrome bloque le collage :
1️⃣ Tape : Allow pasting dans la console
2️⃣ Appuie sur Entrée
3️⃣ Recolle ensuite ton script.

Tu n'auras plus besoin de le refaire après (pour cette session).
Exemple – Simple action

Objectif : lancer automatiquement une petite pause.

Scénario : tu veux que le bouton Pause soit cliqué à 18:30:00.

Dans l’outil, tu choisis :

  • Type d'automatisation : Simple action
  • 1. Premier bouton : Bouton Pause (#PauseToggleBtn)
  • Heure : 18:30:00

Résultat : à 18h30, l’outil clique sur le bouton Pause une fois (comme si tu avais cliqué toi-même).

Exemple – Triple action
Exemple concret avec tes 3 blocs : Supposons que ton planning du jour soit : 11h00–15h00 → Production 15h00–16h00 → Pause déjeuner 16h00–20h00 → Production Tu peux faire dans l’outil : Type d’action : Triple 1er bouton : Bouton Play (tâche visible) → heure : 11:00:00 2e bouton : Bouton Play (tâche visible) → heure : 15:00:00 3e bouton : Bouton Play (tâche visible) → heure : 16:00:00 Résultat : 11h00 → il clique sur le Play visible → ça lance la 1ère Production 15h00 → à ce moment-là, le Play visible sera sur Pause déjeuner → ça lance la pause 16h00 → le Play visible sera sur la Production suivante → ça lance la prod
